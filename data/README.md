# 배합표·루트 자료

`recipes-source.csv`는 제공된 원본 배합표이며, 특급 목재의 최상급 목재+ 소모량 5개를 반영했습니다.
실행 시에는 `recipes.json`이 EXE에 내장됩니다. `Name`은 정확한 게임 가공법 이름, `Product`는 생산품, `ProducedPerWork`는 1회 생산량, `Ingredients[].Count`는 1회 소모량입니다. 실제 가공 횟수 계산은 게임 응답의 ProducedPerWork를 우선 사용합니다.
철괴는 `철괴(광석)`, `철괴(철 광석)`으로 분리합니다. 배합표에 없는 하위 가공법을 임의 추측하지 않습니다.
사용자 설정의 배합표 가져오기는 같은 이름을 교체하고 다른 이름을 유지합니다.

## 개별 루트 공유 JSON

```json
{"Version":1,"Route":{"Id":"unique-route-id","Name":"내 루트","Material":"통나무","Skill":"벌목","MinLevel":1,"MaxLevel":20,"DeviationMode":"corridor","Tolerance":10,"Points":[{"Area":"게임 지역 이름","X":0,"Y":0}]}}
```

위 좌표는 형식 예시이며 실제 추천 위치가 아닙니다. 재료용 루트는 Skill을 빈 문자열로 지정합니다. 구간 끝 레벨도 포함합니다.
공유 문자열은 `ERIN-ROUTE-1:` 뒤에 이 JSON의 UTF-8 Base64를 붙인 형식입니다. 앱에서 복사/가져오기를 지원합니다.
가져온 루트는 새 ID로 저장되며 기존 루트를 덮어쓰지 않습니다. 재료별 기본 선택은 공유 데이터에 포함하지 않습니다.

## 제작자 기본 루트

`routes.json`의 `Routes` 배열에 위 Route 객체들을 넣으세요. 각 Id는 서로 다른 고정 문자열이어야 합니다.
이 파일은 빌드 때 EXE에 포함되며, 신규 설정의 기본 루트 또는 기존 설정에서 '기본 프리셋 불러오기'로 추가됩니다.
루트의 자동 이동/실행 연동은 게임 커넥터의 관련 API가 제공된 뒤 구현할 예정입니다.

DeviationMode는 corridor(경로 선분에서 벗어남) 또는 radius(시작점 반경)입니다. Tolerance는 게임 좌표 단위의 허용 거리이며 기본 10입니다. 첫 지점이 시작·복귀 위치입니다. 경로의 다른 지역으로 벗어난 경우에도 이탈로 판정합니다.
