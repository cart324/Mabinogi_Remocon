# 에린 리모컨 1.4.2

실행: `dist\ErinRemote.exe`. Windows 10/11, .NET Framework 4.8 이상. Python이나 AI 구독은 필요하지 않습니다.
게임에 캐릭터로 접속하고 AI 커넥터를 켜세요. 기본 게임 CLI 경로는 `C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe`이며 설정에서 바꿀 수 있습니다.

## 가공 시설

6개 시설은 작업이 없어도 항상 표시합니다. 시설마다 전체 슬롯을 따로 지정할 수 있습니다. 현재 기본값은 각각 7칸입니다.
**시설별 슬롯 설정**에서 각 캐릭터의 시설 레벨에 맞게 바꾸세요. 게임은 전체 슬롯 수와 시설 레벨을 API로 알려주지 않습니다.
빈 슬롯 = 설정한 전체 슬롯 - 게임에서 조회한 작업 수. 완료됐지만 미수령인 작업도 슬롯을 차지합니다.
최종 완료 남은 시간은 진행 작업의 잔여 시간과 모든 대기 작업의 소요 시간을 합산합니다.
0칸으로 설정하면 해당 시설에 등록하지 않습니다. 실제 점유 수가 설정 수보다 많으면 빨간색으로 표시합니다.

## 자동 가공

시설 선택 → 목표 추가 → 품목과 반복 방식 설정 → 상단 자동화 시작.

- 목표 보유 수량: 보유 재고와 대기열 생산량을 함께 계산합니다.
- 등록 횟수: 지정 횟수만큼 성공적으로 등록합니다. 진행 횟수는 저장되며, '횟수 초기화'로 다시 시작할 수 있습니다.
- 무제한: 빈 슬롯이 생길 때마다 반복합니다. 가방 한도는 적용됩니다.

완료 가공물 수령 → 목표 가공 및 하위 재료 보충 → 부족 재고 채집 → 빈 시간 낚시 순서로 진행합니다.
제공된 배합표로 시설 슬롯 수까지 한 묶음의 재료를 먼저 확보합니다. 이미 보유한 재료와 등록된 하위 작업의 생산 예정량은 제외합니다.
예: 목재+ 등록 4회는 목재 12개 + 나무 진액 16개, 7슬롯의 무제한/10회 목표는 우선 목재 21개 + 나무 진액 28개를 준비합니다.
목재 21개를 만드는 7회분은 통나무 70개를 준비합니다. 실제 채집 API는 수량 지정이 없어 한 번에 최대 100개씩 채집할 수 있습니다.
하위 재료도 시설별 슬롯 수까지 나눠 준비합니다. 같은 시설에서 하위 작업을 등록해도 상위 묶음 준비 목표가 줄어들지 않습니다.
완제품 보유 목표는 실제 생산량을 반영합니다. 목재+ 보유 목표 4개와 등록 목표 4회는 다릅니다.
배합표는 `data/recipes.json`에 내장된 50종을 사용합니다. 표가 없는 가공법은 자동 등록하지 않으며, 수동 가공은 기존처럼 가능합니다.
배합표는 프로그램에 내장되며 사용자 화면에서 가져오기·내보내기는 제공하지 않습니다.
가공법별 시설 정보는 API에 없어 기본 분류를 적용합니다. 분류가 다른 품목은 **전체 가공법 보기**에서 선택하세요. 선택한 시설로 분류가 저장됩니다.
가공 단위에 따라 목표 보유 수량을 소폭 초과할 수 있습니다.

## 수동 가공

시설 선택 → 품목 선택 → 선택 품목 예약 → 빈 슬롯 일괄 등록.
예약 창의 기본 수량은 현재 남아 있는 빈 슬롯 전체입니다. 여러 품목으로 나눠 예약할 수도 있습니다.
실행 직전에 실제 점유 수를 다시 조회해, 그 시점의 빈 슬롯을 넘지 않도록 한 번만 등록합니다. 완료 후 자동 재등록하지 않습니다.
가공물이 완료되어도 수령하지 않았다면 슬롯이 비지 않습니다. '일괄 수령' 후 등록하세요.

## 상태·재고·낚시

- 상단에는 현재 위치, 행동, 가방 무게, **가방의 정령의 날개 잔량**이 항상 표시됩니다. 조회 실패 시 마지막 값과 경과 시간을 함께 표시합니다.
- 재고는 가방·계정 창고·캐릭터 창고별로 볼 수 있습니다. 목표 재고와 자동 채집을 설정할 수 있습니다.
- 채집은 게임 명령상 최대 100개 묶음 단위입니다. 목표 수량을 초과할 수 있습니다.
- 낚시 목록은 현재 게임에서 조회된 물고기만 표시합니다. 낚시터 선택 인수는 제공되지 않아 목적지는 게임이 결정합니다.
- 빈 시간 낚시 ON과 자동화 시작이 모두 켜져야 자동 낚시를 시작합니다. 다른 예약이 생기면 리모컨이 시작한 낚시를 멈춥니다.
- 아이콘은 재고 화면에서 이미지 파일을 직접 지정할 수 있습니다.

## 실행과 대기

시작·일괄 등록·수령 시 별도 확인창 없이 실행합니다. 입력 오류나 조건 부족은 화면 아래와 기록에 표시합니다.
작업 후 고정 대기 10초는 제거했습니다. 필요한 상태를 갱신한 다음 다음 예약을 즉시 실행합니다.
예약이 없을 때는 자동화 중 약 1초, 일반 상태 약 3초 간격으로 게임 상태를 다시 확인합니다. 가공법과 채집 목록은 필요 시 또는 약 60초마다 갱신합니다.
이동·수령 등의 게임 내부 처리와 CLI 응답을 기다리는 시간은 남습니다. 기록에서 '게임 명령 응답' 시간과 '작업 후 상태 갱신' 시간을 구분할 수 있습니다.
'예약 일시정지'는 다음 예약을 막고, '중지'는 현재 리모컨 작업에 중지 명령을 보냅니다. 게임 단계에 따라 즉시 중단되지 않을 수 있습니다.
채집 및 가공 등록은 1회당 정령의 날개 5개를 사용합니다. 날개 예약 예산 기능은 제거되었으며, 실제 보유 수량은 상단에 표시됩니다. 앱 실행 시 자동화는 항상 OFF입니다.

## 지원하지 않는 기능

자동 판매·분해·창고 이동, 던전/사냥터 입구 자동 이동, 은동전·공물 소비, 특정 낚시터 지정은 게임 커넥터에 명령이 없습니다.
가방 한도에서는 중지·정리 알림을 냅니다. 입구 위치 저장·도착 알림과 던전 Cleared 상태 알림은 지원합니다.

## 프로젝트

- `src`: C# 소스 및 내장 게임 명령 규격
- `dist\ErinRemote.exe`: 실행 파일
- `build.cmd`, `build.ps1`: 빌드
- `test.ps1`, `tests`: 검증
- `work`: 개발·검증 자료 (배포본에는 개인 게임 조회 자료를 포함하지 않습니다)
- `%LOCALAPPDATA%\MabiRemote`: 사용자 설정·아이콘·기록

`--demo`로 게임 조작 없는 데모를 실행할 수 있습니다.

## 업데이트와 배포

실행 파일은 [GitHub Releases](https://github.com/cart324/Mabinogi_Remocon/releases/latest)의 Assets에서 받으세요.
1.3.1부터 **업데이트** 탭에서 실행 시 자동 확인을 켜고 끌 수 있습니다. 자동 확인은 실행할 때 1회 수행합니다.
**릴리스 페이지 열기** 버튼으로 GitHub를 열고 Assets의 ErinRemote.exe를 받으세요.
리모컨 작업을 중지·종료한 뒤 기존 EXE에 덮어쓰세요. 설정은 실행 파일과 별도 저장되어 유지됩니다.
네트워크 오류나 GitHub 조회 한도는 게임 작업을 중지하지 않습니다. 앱에서 파일 다운로드·교체·재시작을 하지 않습니다.

개발 파일 백업은 이 저장소에서 관리합니다. `work`의 개인 게임 조회 자료와 사용자 설정·로그는 제외합니다.
배포 방법:

1. `src/Updates.cs`의 CurrentVersion과 `src/VersionInfo.cs`의 파일 버전을 함께 올리고 RELEASE_NOTES.md를 수정합니다.
2. 변경 파일을 커밋합니다.
3. PowerShell에서 `./release.ps1 -Version 1.3.1`처럼 실행합니다.
4. GitHub Actions가 테스트 후 태그에 맞는 EXE, SHA256SUMS.txt, 소스 ZIP을 Releases에 게시합니다.

새 버전은 항상 새 태그로 게시합니다. 기존 릴리스 파일은 교체하지 않습니다. 빌드 실패는 저장소 Actions에서 확인하세요.

## 채집 루트 준비 (1.4.0)

현재 커넥터는 좌표 이동, 사용자 경로 지정, 생활스킬 레벨 조회를 지원하지 않습니다. 이 화면은 루트 설계·공유 준비용이며 실제 채집은 게임이 선택한 기본 경로를 사용합니다.

- **채집 루트 → 새 루트**: 재료와 이름을 정하고 현재 위치 또는 지역/X/Y 지점을 순서대로 추가합니다. 저장 장소에서도 지점을 선택할 수 있습니다.
- **재료 기본 루트로 선택**: 재료마다 하나의 프리셋 선택을 저장합니다. 다른 루트를 선택하면 기존 선택을 대체합니다.
- 생활스킬 이름과 최소/최대 레벨을 기록하고, 레벨 필터로 해당 구간의 루트를 조회합니다. 레벨은 직접 지정하며 자동 조회·레벨링은 아직 실행하지 않습니다.
- **파일 내보내기/가져오기**: JSON 파일로 공유합니다. **공유 문자열 복사/가져오기**도 지원합니다.
- 첫 번째 지점은 시작·복귀 위치이며 나머지 지점은 허용 경로입니다. 기본 이탈 기준은 경로 선분과의 거리입니다. 루트마다 허용 거리를 지정하며, 시작점 반경 방식도 선택할 수 있습니다.
- 설계된 실행 순서는 시작점 이동 → 재료 채집 → 경로 이탈 시 중지·복귀 → 재시도입니다. 이동 API가 없으므로 이 반복 실행은 아직 연결하지 않습니다. **현재 위치로 이탈 확인**은 마지막 조회 위치를 기준으로 판정만 합니다.
- 재고·채집/채집 루트 탭에서 리모컨이 실행한 채집의 진행 중·완료·중단·오류 및 획득 수량을 표시합니다. 명령이 이동을 포함해 실행되므로 진행 중 표시는 이동 단계도 포함합니다.
- 채집은 최대 100개 획득 단위이며 1회/수량 지정 인수는 없습니다. `stop_action`으로 진행 중 중지 요청은 가능합니다. 루트별 위치 감시·자동 중지·복귀는 아직 실행하지 않습니다.
- 제작자 기본 프리셋은 `data/routes.json`에 넣어 빌드하면 EXE에 포함됩니다. 현재 기본 루트는 비어 있으며 임의 경로는 만들지 않았습니다. 기존 사용자는 **기본 프리셋 불러오기**로 추가할 수 있습니다.
- 루트 자료와 사용자별 선택은 기존 설정 폴더에 저장됩니다. 가져온 파일은 데이터로만 처리하며 코드나 명령을 실행하지 않습니다.

파일 규격은 `data/README.md`를 참고하세요.

## 알림 (1.4.1)

게임 오류는 재료 부족·날개 부족·도구 파손·길 찾기 실패 등 상황에 맞는 한글 안내로 표시합니다. 상세 오류 원문은 설정·기록에 남깁니다. 알 수 없는 오류도 영문 코드 대신 한글 확인 안내를 표시합니다.
