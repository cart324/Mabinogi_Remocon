# 에린 리모컨 2.1.1 (ErinRemote)

마비노기 모바일 연동 생활 보조 및 편의 도구입니다.

---

## 1. 시작하기

### 실행 환경
- **운영체제**: Windows 10 / 11 (64-bit)
- **런타임**: .NET Framework 4.8 이상
- 별도의 Python 설치나 외부 AI 서비스 구독 없이 실행할 수 있습니다.

### 실행 및 연결
1. `dist\ErinRemote.exe`를 실행합니다.
2. 게임에 캐릭터로 접속한 후 **AI 커넥터** 기능을 활성화합니다.
3. 리모컨 상단에 **연결됨** 상태가 표시되면 정상 동작합니다.
   - 게임 CLI 경로 기본값: `C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe`
   - 최초 실행 시 파일이 없으면 선택 창이 열리며, 우상단 **설정**에서 언제든 변경할 수 있습니다.

---

## 2. 주요 기능

### ① 가공 시설 & 자동 가공
- **가공 시설 모니터링**: 6개 시설의 가공 현황, 남은 시간, 빈 슬롯 수를 실시간으로 확인합니다.
- **자동 가공 목표**:
  - 목표 품목, 목표량(보유 수량 또는 등록 횟수)을 등록하고 상단 **자동화 시작**을 누르면 자동으로 가공을 진행합니다.
  - 목록의 **활성화** 열을 클릭하여 개별 목표의 동작 여부를 전환할 수 있습니다.
  - 목표 순서(우선순위)에 따라 상위 항목부터 처리됩니다.
  - **부족 재료 자동 보충**: 상위 품목 가공에 필요한 재료가 부족할 경우, 하위 가공 및 채집을 자동으로 연계합니다.

### ② 수동 가공
- 가공 시설과 품목을 선택하고 수량을 입력하여 즉시 예약합니다.
- **수령 후 일괄 등록**: 완료된 품목을 자동으로 수령한 뒤 빈 슬롯에 예약한 수량만큼 즉시 가공을 등록합니다.

### ③ 재고 및 채집
- **재고 조회**: 가방, 계정 창고, 캐릭터 창고의 보유 수량을 확인하고 아이템 검색을 지원합니다.
- **자동 채집**: 목표 수량을 설정하면 부족한 재료를 자동으로 채집합니다. 가방 용량 한도에 도달하면 안전하게 채집을 중지합니다.

### ④ 자동 낚시
- 가공이나 채집 작업이 없을 때 지정한 어종을 자동으로 낚시합니다.
- 새 가공·채집 작업이 발생하거나 가방 용량 한도에 도달하면 낚시를 자동으로 멈춥니다.

### ⑤ 주크박스
- 보유 악보를 등록하여 원하는 순서대로 자동 연속 연주할 수 있습니다.
- 곡별 사용 악기 지정, 목록 반복 재생 기능을 지원합니다.

### ⑥ 채집 루트 관리
- 채집 경로의 시작점과 경유 지점, 이탈 허용 거리를 설정하여 관리합니다.
- 루트 프리셋 파일(JSON) 내보내기/가져오기 및 클립보드 공유 코드를 지원합니다.
- **편집기 활성화/비활성화**: 기본적으로 채집 루트 탭은 숨김 상태(기본값 비활성화)입니다. 우상단 [설정]에서 언제든 체크하여 탭을 표시할 수 있습니다.
- **채집 시 채집 루트 사용**: 채집 작업 시 설정된 루트 경로 및 이탈 감지를 적용할지 여부를 선택할 수 있습니다 (기본값 활성화).

## 3. 알림 및 설정

우상단 **설정** 버튼을 통해 다음 옵션을 지정할 수 있습니다:

- **가방 용량 한도**: 지정한 비율(기본 95%)에 도달하면 작업을 멈추고 알림을 표시합니다.
- **UI 배율**: 70% ~ 125% 범위에서 텍스트 및 화면 크기를 조절할 수 있습니다.
- **채집 루트 편집기 활성화**: 채집 루트 탭의 표시/숨김을 설정합니다 (기본값: 비활성화).
- **채집 시 채집 루트 사용**: 채집 시 루트 지점 및 허용 범위 적용 여부를 선택합니다 (기본값: 활성화).
- **활동 알림**:
  - 던전 완료 시 알림
  - 사냥터 임무 완료 시 알림
  - 검은 덩어리 보유량 초과 알림
  - 가방 100% 초과 알림
- **시설별 슬롯 설정**: 캐릭터의 시설 레벨에 맞춰 시설별 최대 슬롯 수를 지정합니다 (기본 7칸).

## 4. 빌드 및 테스트

개발 및 빌드는 PowerShell 스크립트를 통해 간편하게 수행할 수 있습니다.

```powershell
# 프로젝트 빌드
.\build.ps1

# 전체 단위 테스트 실행
.\test.ps1

# 데모 모드로 실행 (게임 연결 불필요)
.\dist\ErinRemote.exe --demo
```
